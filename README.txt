KOTA RAYA DRIVE - paket siap APK

1. Unggah SEMUA file di folder ini ke hosting statis gratis (Netlify, GitHub Pages, atau Cloudflare Pages) sehingga dapat alamat https.
2. Buka pwabuilder.com, tempel alamat itu, pilih Android, lalu unduh paketnya.
3. Di dalam zip hasilnya ada file .apk (untuk dibagikan langsung) dan .aab (untuk Google Play).
   Penerima perlu mengizinkan pasang dari sumber tidak dikenal.

Catatan: pertama kali dibuka butuh internet (memuat three.js), sesudah itu bisa offline. Tampilan dikunci landscape.
